# 用户指南

## 快速开始

### 1. 安装和配置

#### 系统要求
- Windows 10/11
- Python 3.8 或更高版本
- 4GB 以上内存
- 稳定的网络连接

#### 安装步骤

1. **下载项目**
   ```bash
   git clone <repository-url>
   cd WechatContentGen
   ```

2. **创建虚拟环境**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **配置API密钥**
   
   编辑 `config/api_keys.py` 文件，添加您的API密钥：
   ```python
   OPENAI_API_KEY = "sk-your-openai-api-key"
   STABILITY_AI_KEY = "sk-your-stability-ai-key"
   ELEVENLABS_API_KEY = "your-elevenlabs-api-key"
   ```

### 2. 启动应用

运行以下命令启动应用：
```bash
python main.py
```

## 主要功能

### 内容生成

1. **创建新文章**
   - 点击工具栏的"新建"按钮
   - 或使用快捷键 `Ctrl+N`

2. **设置文章参数**
   - 主题：输入文章的主要话题
   - 风格：选择写作风格（专业、幽默、严肃等）
   - 长度：选择文章长度（短、中等、长）
   - 关键词：添加需要包含的关键词

3. **生成内容**
   - 点击"生成内容"按钮
   - 等待AI生成完成
   - 在左侧编辑区查看生成的内容

4. **编辑内容**
   - 在左侧编辑区直接修改内容
   - 支持富文本编辑
   - 实时预览效果

### 配图生成

1. **选择文本**
   - 在编辑区选择需要配图的文本段落
   - 或直接输入图片描述

2. **设置图片参数**
   - 风格：选择图片风格（写实、卡通、抽象等）
   - 尺寸：选择图片尺寸
   - 质量：选择图片质量

3. **生成配图**
   - 点击"生成配图"按钮
   - 等待图片生成完成
   - 在预览区查看生成的图片

4. **插入图片**
   - 将生成的图片插入到文章中
   - 调整图片位置和大小

### 语音生成

1. **选择文本**
   - 选择需要转换为语音的文本
   - 支持选择部分或全部内容

2. **设置语音参数**
   - 语音类型：选择男声或女声
   - 语速：调整语音速度
   - 音调：调整音调高低

3. **生成语音**
   - 点击"生成语音"按钮
   - 等待语音生成完成
   - 在播放器中试听语音

4. **导出语音**
   - 保存语音文件到本地
   - 支持多种音频格式

### 富文本预览

1. **实时预览**
   - 在右侧预览区实时查看文章效果
   - 支持微信公众号格式预览

2. **样式调整**
   - 调整字体、颜色、间距等
   - 应用预设的排版模板

3. **导出功能**
   - 导出为HTML格式
   - 导出为Markdown格式
   - 导出为Word文档
   - 导出为PDF文件

## 常见问题

### Q: 如何获取API密钥？

**A:** 
- OpenAI API密钥：访问 https://platform.openai.com/api-keys
- Stability AI密钥：访问 https://platform.stability.ai/account/keys
- ElevenLabs密钥：访问 https://elevenlabs.io/app/settings/api-keys

### Q: 生成内容质量不满意怎么办？

**A:** 
- 尝试调整提示词和参数
- 使用更具体的主题描述
- 添加相关关键词
- 选择合适的写作风格

### Q: 图片生成失败怎么办？

**A:** 
- 检查网络连接
- 确认API密钥正确
- 尝试简化图片描述
- 检查API配额是否充足

### Q: 如何提高生成速度？

**A:** 
- 使用更快的AI模型
- 减少内容长度
- 优化网络连接
- 考虑使用本地模型

### Q: 如何备份我的内容？

**A:** 
- 定期导出重要内容
- 使用云存储同步数据目录
- 设置自动备份功能

## 技巧和建议

### 内容生成技巧

1. **明确主题**：使用具体、清晰的主题描述
2. **添加关键词**：包含相关的行业术语和热门词汇
3. **选择合适风格**：根据目标读者选择写作风格
4. **分段生成**：对于长文章，可以分段生成后合并

### 配图技巧

1. **描述具体**：使用详细的视觉描述
2. **风格一致**：保持整篇文章的图片风格统一
3. **尺寸适配**：选择适合微信公众号的图片尺寸
4. **版权注意**：确保生成的图片符合使用要求

### 语音技巧

1. **断句处理**：在长句子中添加适当的停顿
2. **语速调节**：根据内容类型调整语速
3. **音调变化**：使用不同音调增加表现力
4. **格式选择**：根据用途选择合适的音频格式

## 故障排除

### 常见错误及解决方案

1. **API密钥错误**
   - 检查密钥格式是否正确
   - 确认密钥是否有效
   - 检查API配额是否充足

2. **网络连接问题**
   - 检查网络连接
   - 尝试使用VPN
   - 检查防火墙设置

3. **依赖包问题**
   - 重新安装依赖包
   - 检查Python版本兼容性
   - 使用虚拟环境

4. **文件权限问题**
   - 检查文件夹权限
   - 以管理员身份运行
   - 更改文件保存位置
